# Goondan 저장소 분석 비교 실험

이 폴더는 같은 저장소 분석을 단일 에이전트와 분석·편집 직렬 flow로 실행하여 최종 보고서의 차이를 비교하는 재사용 가능한 실험 자산을 담습니다.

## 구조적 결정

1. `common/goondan.yaml`이 두 실험에서 사용하는 분석 에이전트 정의를 소유합니다.
이유: 분석 모델, 도구와 시스템 프롬프트를 한곳에 두어 두 조건의 원분석을 같은 계약으로 유지하기 위해서입니다.
2. 각 조건은 독립적인 진입 구성 디렉터리를 사용합니다.
이유: 서로 다른 세션과 결과 경로로 실행하기 쉽고, 각 구성 자체를 `gdn validate`로 검증할 수 있기 때문입니다.
3. 편집 에이전트는 분석 결과만 입력으로 받고 도구를 사용하지 않습니다.
이유: 편집 단계가 표현과 구성만 다루고 새로운 조사 결과를 보고서에 섞지 않도록 하기 위해서입니다.

## 불변 규칙

- 두 조건은 같은 `prompt.txt`, 같은 저장소 snapshot과 같은 모델을 사용합니다.
- 분석 에이전트의 도구는 읽기 전용 작업에 한정합니다.
- 편집 프롬프트는 분석 사실, 근거와 불확실성을 그대로 보존합니다.
- 두 실행은 서로 다른 새 세션을 사용합니다.
