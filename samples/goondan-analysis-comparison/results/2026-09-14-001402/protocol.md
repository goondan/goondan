# 저장소 분석과 문장 편집 비교 조건

두 구성은 같은 입력과 같은 소스 snapshot을 사용하며, 분석 에이전트 정의를 공유합니다. 모든 모델 호출은 `claude-opus-5`를 사용합니다. 각 구성은 새로운 세션에서 한 번 실행합니다.

| 조건 | 실행 단계 | 비교할 출력 |
|---|---|---|
| 단일 | 분석 에이전트 | 분석 보고서 |
| 직렬 | 분석 에이전트 → 말 다듬기 에이전트 | 말 다듬기 에이전트의 최종 보고서 |

소스 snapshot에는 현재 미커밋 변경을 포함한 430개 파일이 있습니다. Git 메타데이터, 의존성·빌드 산출물, 환경·자격증명 파일과 이 실험 폴더는 제외했습니다. 파일별 해시는 `source-manifest.json`, 입력은 `input.txt`, 모델·명령·소요 시간은 `metadata.json`에 기록합니다. 두 프로세스를 함께 시작하며 모델의 서버 부하와 생성 무작위성을 고정하지는 않습니다.

말 다듬기 에이전트는 도구 없이 분석 보고서만 입력받습니다. 일상 용어 또는 업계 표준 용어를 사용하고, 독자를 배려하는 친절한 말투로 쓰며, 독자가 논지를 순차적으로 따라갈 수 있도록 구성합니다. 사실, 근거, 불확실성은 보존하도록 지시합니다.

`single.md`와 `edited.md`는 `--final-only`의 표준 출력을 그대로 저장합니다. 중간 응답은 비교 출력에 포함하지 않습니다. 세션과 실행 상태 로그는 사실 보존과 실행 경로를 확인하는 근거로 보관합니다. 터미널의 진행 상황 표시 방식은 이번 비교의 평가 범위에 포함하지 않습니다.

문장 평가는 익숙한 용어, 독자에 대한 배려, 논지 전개와 정보 밀도를 기준으로 합니다. 편집 과정의 사실 보존은 직렬 구성 내부의 편집 전·후 보고서를 비교해 판단합니다. 두 구성에서 분석 단계 자체가 서로 다른 결과를 만들 수 있으므로, 최종 출력 차이 전체를 편집 단계의 효과로 해석하지 않습니다. 이번 결과는 각 조건 한 번씩 실행한 탐색적 비교입니다.
