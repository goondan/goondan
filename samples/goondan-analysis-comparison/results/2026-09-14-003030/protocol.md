# 비교 조건

두 구성은 같은 입력, 같은 소스 복사본, 같은 분석 에이전트 정의와 `claude-opus-5` 모델을 사용합니다. 각 구성은 새 세션에서 시작합니다. 단일 구성은 분석 보고서를 출력하고, 직렬 구성은 분석 뒤 말 다듬기 에이전트의 최종 보고서만 출력합니다.

모델 요청과 실험 전체에 자동 시간 제한을 두지 않습니다. 소스 복사본에는 CLI의 모델 요청 타이머 제거와 실패 종료 코드 수정이 포함됩니다. 실제 구성, 프롬프트, 소스 파일별 해시, 로그와 세션을 함께 보존합니다. 앞선 실패·중단 실행은 품질 비교에서 제외합니다.

공통 분석 프롬프트는 도구 호출을 12회 이내로 마치고 확보한 근거로 보고서를 작성하도록 지시합니다. 말 다듬기 에이전트에는 도구를 제공하지 않습니다. 두 분석이 각각 생성되므로 최종 출력의 차이 전체를 편집 효과로 해석하지 않습니다. 편집의 사실 보존은 직렬 구성 내부의 편집 전후 보고서로 확인합니다.

각 조건을 한 번씩 실행한 탐색적 비교입니다. 익숙한 용어, 독자에 대한 배려, 논지 전개와 정보 밀도를 기준으로 읽기 쉬움을 평가합니다. 터미널의 진행 상황 표시 방식은 이번 비교의 범위에 포함하지 않습니다.
